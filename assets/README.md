# Brushed gunmetal texture

`brushed-gunmetal.jpg` is a project-owned texture generated with the built-in image-generation tool, then encoded as JPEG for the website. The card surfaces use this raster texture beneath a dark overlay. Helvetica text and the metallic border remain separate HTML/CSS.

## Generation prompt

Use case: photorealistic-natural
Asset type: seamless brushed-metal texture for the background of website cards.
Primary request: A flat, full-frame scan of real dark gunmetal with clearly visible fine horizontal brushing. Dense, irregular hairline scratches of varied lengths and spacing, subtle anisotropic silver grain, satin finish. The texture must visibly read as brushed steel at normal screen size, with natural microscopic variation rather than perfectly repeated stripes.
Composition: square 1024 x 1024, orthographic, edge-to-edge material only, tileable seamless edges.
Lighting: even diffuse illumination, no bright hotspot, no vignette, no large gradients or reflected shapes.
Palette: strictly neutral charcoal grey and silver; medium-dark values with enough grain contrast to remain visible after a dark website overlay. No purple, blue, brown or other colour cast.
Avoid: text, logos, watermarks, frames, bevels, objects, screws, panels, large gouges, rust, circular machining marks, fabric, wood grain. Generate only the material texture, not a website mockup.
